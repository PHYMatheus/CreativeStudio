# Creative Studio - Landing Page

HTML único (CSS e JS dentro do index.html). Abra com a extensão Live Server do VS Code.

## Estrutura
creative-studio/
├── index.html
├── README.md
└── assets/
    ├── logo.png               (logo com fundo transparente)
    ├── sara-ilustracao.jpg    (ilustração da Sara)
    └── projetos/              (coloque aqui as imagens dos trabalhos)

## O que editar (bloco CONFIG no <script>, no fim do index.html)
- whatsapp: número com DDI + DDD, só dígitos (ex.: 5581999999999)
- instagram: link do perfil
- PROJETOS: lista de imagens em assets/projetos/ (troque os nomes se quiser)

## Animações da ilustração (CSS, dentro do <style>)
- .sp = brilhos (posição, tamanho e atraso no style de cada <svg> no HTML)
- .arch::after = reflexo de luz
- .float = flutuação suave
- .heart = corações subindo
Tudo desliga sozinho pra quem usa "reduzir movimento" no aparelho.
