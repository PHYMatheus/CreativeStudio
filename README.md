# Creative Studio · Landing Page

Landing page da **Creative Studio**, estúdio de artes digitais que atende online pelo Instagram.

🔗 **Ver online:** [CriativeStudio.vercel.app](https://creativestudio-dun.vercel.app/)

## Tecnologias

HTML5, CSS3 e JavaScript puro. Hospedado na Vercel.

## Como rodar

Abra a pasta no VS Code e use a extensão **Live Server** no `index.html`.
